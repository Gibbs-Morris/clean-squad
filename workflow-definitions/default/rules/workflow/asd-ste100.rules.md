# ASD-STE100 Rules (RFC 2119)

- You MUST use ASD-STE100 Simplified Technical English, Issue 9, for natural-language output.
- You MUST use the same term for the same item throughout the output.
- You MUST use active voice when practical.
- You MUST limit each procedural sentence to 20 words.
- You MUST limit each descriptive sentence to 25 words.
- You MUST give only one instruction in each sentence.
- You MUST preserve literal code, commands, paths, identifiers, schemas, logs, quoted text, headings, and required output tokens.
- You MAY use necessary project terms as technical nouns or technical verbs.
- You MUST check the output against the shared ASD-STE100 guidance before you return it.
