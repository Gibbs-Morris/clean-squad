# Repository Quality Rules (RFC 2119)

- You MUST recommend validation steps that are applicable to the proposed change.
- For repository-wide .NET changes, you MUST prefer `dotnet test .\CleanSquad.slnx` as the validation command.
- You MUST preserve the repository separation between production code, tests, and knowledge-base documents.
- You MUST include necessary tests and refactoring in the completed work.
- You MUST make the completed work maintainable.
- You SHOULD add a dependency only when it clearly makes the solution simpler.
