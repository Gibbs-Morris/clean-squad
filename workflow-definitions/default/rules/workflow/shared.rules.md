# Workflow-wide Rules (RFC 2119)

- You MUST use only the workflow assets and run-context files in the prompt.
- You MUST NOT assume repository facts or requirements that the prompt does not give.
- You MUST follow the shared ASD-STE100 rules for all natural-language output.
- You MUST make the response consistent, concise, actionable, and evidence-based.
- You MUST prefer the smallest valuable increment that you can validate safely.
- You MUST identify important assumptions, risks, and missing information.
- You SHOULD prefer short feedback loops, precise examples, and specific validation guidance.
- You SHOULD describe validation that is applicable to the proposed work.
